# Spatz Internal Catalog

A high-performance e-commerce product catalog featuring 10,000+ SKUs with integrated search, filtering, and product management.

## Features

- **10,000+ Products** - Complete product database with images, prices, and specifications
- **Fast Search** - Client-side search and filtering for instant results
- **Product Details** - Rich product information including descriptions, pricing, and stock status
- **Category Navigation** - Organized product categories with intelligent synonym mapping
- **Image Gallery** - High-quality product images with optimized loading
- **Responsive Design** - Works seamlessly on desktop and mobile devices

## Files

- `index.html` - Main catalog application (single-page app)
- `products.json` - Complete product database with 10,000+ entries
- `synonym_map.json` - Category synonym mappings for better search
- `SKU_Database.xlsx` - Product reference spreadsheet
- `images/` - Product image assets

## Getting Started

### Local Testing
1. Clone this repository
2. Open `index.html` in a web browser
3. Browse products, search, and filter by category

### Deployment
The catalog is a static website and can be hosted on:
- GitHub Pages (free)
- Netlify
- Vercel
- Traditional web hosting

Simply upload the files to your hosting provider.

## Usage

- **Search**: Use the search bar to find products by name or description
- **Filter**: Click category tags to filter products
- **Sort**: Sort by price, popularity, or name
- **View Details**: Click any product to see full specifications

## Technical Stack

- **Frontend**: HTML5, CSS3, JavaScript (vanilla)
- **Data Format**: JSON
- **No Backend Required**: Static site with client-side processing
- **Fully Self-Contained**: All code and data in single directory

## Performance

- Single page load with all products cached
- Optimized JSON data structure
- Client-side filtering (instant results)
- Fast image loading with lazy loading support
